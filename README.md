# PSE-TVD
[CGW2022 Best Paper Award] ["PSE-TVD: Parameter Space Exploration for Time-Varying Ensemble Data Visualization and Analysis"](https://github.com/littlepenguin89106/PSE-TVD/blob/main/PSE_TVD_CGW2022.pdf)

# The Used Datasets
> [!IMPORTANT]
> Most of the original datasets are lost or no longer accessible. The available sources and generation methods are listed below.

- [Deep Water Asteroid Impacts](https://oceans11.lanl.gov/deepwaterimpact/)
- [Hurricane Isabel](https://huggingface.co/datasets/sdrbench/hurricane-isabel) (Unofficial mirror)
- [Nyx](https://amrex-astro.github.io/Nyx/) (Original data unavailable; generate it with Nyx.)
